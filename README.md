## 🚀 Featured Projects

### 📺 1. OTT Platform Viewing Patterns Analysis

**Objective:** Analyze viewer engagement, content performance, and customer retention to support data-driven content decisions.

- 📊 Analyzed **63,797 records across five datasets**.
- 🐍 Used Python and Pandas for data cleaning and exploratory data analysis.
- 🗄️ Used SQL to analyze viewing patterns and customer behaviour.
- 📉 Applied statistical tests and linear regression.
- 📈 Created interactive Power BI dashboards to communicate insights.

**Key findings from the project:**
- Customer churn was approximately **44.4%**.
- Free Trial customers had a higher churn rate than paid-plan customers in the analyzed data.
- Movies had a higher average completion rate than TV shows in the analyzed data.

🔗 **[View OTT Platform Analytics on GitHub](https://github.com/rutujaparab20/OTT-Platform-Viewing-Patterns-Analysis)**
